Embedded panel · anonymous visitor

The component fills whatever box you give it and inherits your app's font. This instance has no token, so it behaves like the public website chat.

Floating launcher · signed-in user

Bottom-right "ask" button. This instance carries a token minted by the server for a sample user, so the assistant greets them by name and books without asking for name or email.
